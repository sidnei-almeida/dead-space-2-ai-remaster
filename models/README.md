# Modelos

Coloque aqui os modelos de upscale (`.pth` ou `.safetensors`). Eles não vão para o git.

Onde baixar: https://openmodeldb.info

Sugestões para começar:

| Uso | Tipo de modelo |
|---|---|
| `--model` | 4x para texturas de jogo ou fotos realistas (ex.: 4x-UltraSharp) |
| `--cleanup` | 1x para remover artefatos de compressão DXT/BC1 |

Qualquer arquitetura que o [spandrel](https://github.com/chaiNNer-org/spandrel) carregue funciona (ESRGAN, SPAN, DAT, HAT, etc.).
